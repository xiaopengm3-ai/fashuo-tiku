# 法硕真题 · 刷题台

**在线版：<https://xiaopengm3-ai.github.io/fashuo-tiku/>**

一个**只在本地运行**的法硕历年真题刷题网页。把 2010—2026 年法学/非法学的客观题与主观题按**刑法、民法、法理学、宪法、法制史**整理，并依据五本《背诵一本通》的目录建立考点分类；支持白天/黑夜双主题、答题判分、参考答案、进度记录、错题本与收藏。

## 快速开始

双击 `start.command`，浏览器会自动打开：

```
http://127.0.0.1:8765/
```

也可以在终端手动启动：

```bash
cd app
python3 -m http.server 8765 --bind 127.0.0.1
```

然后访问 <http://127.0.0.1:8765/>。**不要直接双击 `app/index.html`**，浏览器会因本地文件跨域策略而无法读取题库。

## 功能

- **两大页面**：客观题（单项/多项选择）与主观题（简答、法条分析、案例分析、论述、辨析）。
- **两种分类**：
  - 按学科：五大学科，显示题量与完成进度。
  - 按考点：依据《背诵一本通》目录整理的专题/编 → 章/节考点树；未自动归类的题目收入“未分类”。
- **筛选**：年份、法学/非法学、专业基础/专业综合、未做/做错/已做/收藏、题干与选项搜索。
- **答题体验**：选项即时选中、提交判分、正确答案与解析、快捷键 A–D / Enter / ← → / S / F。
- **主观题**：本地草稿自动保存、展开参考答案与解析、掌握/模糊/不会自评。
- **进度**：答题记录、正确率、收藏、错题本、题号跳转、随机 20 题、打乱顺序。
- **主题**：白天/黑夜完整适配（背景、文字、卡片、选项、解析、弹窗、输入框、滚动条），跟随系统并可手动切换。
- **移动端**：响应式布局，窄屏下侧栏变为抽屉。

所有进度、收藏和草稿仅保存在当前浏览器的 `localStorage`，不上传服务器。

说明：

- 源文件中没有 2025 年法学（基础课）、2025 年非法学（基础课）试卷，故未收录；2025 年两套综合课已收录。
- 源文件中缺少 2023 年非法学综合课真题（仅有解析），因此该套题的题干未收录。
- 2022/2024 等年份原卷为扫描件，已用 macOS Vision OCR 识别，个别题干、选项可能存在识别误差。
- 少数题目因原卷分栏/跨页或答案表缺失，显示“本题暂无标准答案”（约 60 余道客观题）；不影响继续练习与查看解析。
- 个别主观题原卷未附参考答案。
- 2005—2009 年真题为合订本且格式差异较大，暂未纳入本题库。

## 目录结构

```
app/
  index.html          页面结构
  assets/styles.css   双主题样式
  assets/app.js       交互逻辑
  data/
    taxonomy.json     考点树
    objective.json    客观题
    subjective.json   主观题
    meta.json         统计信息
start.command         本地启动脚本
tools/                题库构建脚本（PDF 提取、OCR、解析、分类）
work/                 中间产物（文本、OCR、截图）
```

## 重新生成题库（可选）

开发环境需要 Python 3 与 `pymupdf`，OCR 需要 macOS 的 Vision 框架（`pyobjc-framework-Vision`）。

```bash
python3 tools/build_text.py       # 提取 PDF 文本
python3 tools/build_data.py       # 解析题目与答案解析
python3 tools/classify.py         # 学科 / 考点分类
python3 tools/build_app_data.py   # 生成 app/data/*.json
```

OCR 工具：`tools/ocr_vision.py`；页面截图调试：`tools/cdp.py`。

## 数据来源

题库与考点均来自使用者提供的法硕历年真题/解析 PDF 与五本《背诵一本通》。本项目仅作个人本地学习使用，不包含任何在线服务。
